## Estrutura
- `index.html` — página estática pronta para GitHub Pages, Cloudflare Pages ou qualquer hospedagem de arquivos.

## Publicação sem custo
### GitHub Pages
1. Subir esta pasta para um repositório.
2. Em **Settings > Pages**, selecionar branch `main` e a pasta raiz (`/`) ou mover os arquivos para a raiz de um repositório dedicado.
3. Publicar.

### Cloudflare Pages
1. Conectar o repositório.
2. Framework preset: `None`.
3. Build command: vazio.
4. Output directory: `projects/jessica-farm/landing-page` (ou repo raiz, se usar um repo dedicado).
